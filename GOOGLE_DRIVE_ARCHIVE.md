This index links each available experiment/run to its original notebook (or notebook section/run identifier), original output directory, and relevant checkpoint location. The Drive folders are live archives; open them to inspect saved CSVs, histories, predictions, figures, configs and PT files where present. GitHub contains code and tracked evidence; large files stay in Drive or GitHub Releases. The curator's copied CSVs are snapshots, not replacement training inputs. Original Colab paths and file names are intentionally preserved.

**Evidence labels:** “notebook not verified” means the outputs exist but a specific executed notebook has not been established. A link to a shared notebook is not a claim that every cell executed. “Not archived” means no checkpoint is included in the verified source; it does not mean no training occurred. Folder links require source-owner permissions; the lecturer's access has not been verified. Do not run historical notebooks just to inspect results.

**Evaluation rules:** Separate development seen/pseudo-unseen validation from official seen/unseen test results; distinguish the 6,905-image fit from the 8,000-image full-data continuation, and unrestricted 9,625-pair scoring from restricted/calibrated scoring. Some archived tests are retrospective diagnostics, not independent model selection.
